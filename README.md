# Shop the Look — Visual Product Discovery

A complete **"Shop the Look"** system that identifies fashion products in a scene image and retrieves the closest matching items from a product catalog using **CLIP embeddings** and **FAISS** similarity search.

deployment link:
https://shopthelookoptculture-dkpx8drzhusvpiusbig854.streamlit.app/

---

## Architecture

```
Scene Image
    │
    ▼
CLIP Encoder (ViT-B/32)
    │
    ▼  512-dim L2-normalised vector
FAISS Index (cosine similarity)
    │
    ▼
Top-K Nearest Products
    │
    ▼
Attribute-based Explanation
(color · pattern · category · style)
```

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt

# Install OpenAI CLIP (recommended over HuggingFace fallback)
pip install git+https://github.com/openai/CLIP.git
```

### 2. Prepare data

Place your files in `data/`:

```
data/
  catalog.csv          # product IDs (column: product_id)
  validation.json      # [{"scene": "...", "product": "..."}, ...]
```

**Catalog CSV example:**
```csv
product_id
0027e30879ce3d87f82f699f148bff7e
cdab9160072dd1800038227960ff6467
...
```

**Validation JSON example:**
```json
[
  {"scene": "cdab9160072dd1800038227960ff6467", "product": "0027e30879ce3d87f82f699f148bff7e"}
]
```

### 3. Build embeddings

Downloads product images from Pinterest and computes CLIP embeddings.

```bash
python src/build_embeddings.py \
    --catalog data/catalog.csv \
    --output  data/index \
    --workers 8 \
    --batch   64
```

Options:
| Flag | Default | Description |
|---|---|---|
| `--catalog` | required | Path to catalog CSV or JSON |
| `--output` | `data/index` | Where to save the FAISS index |
| `--workers` | 8 | Parallel download threads |
| `--batch` | 64 | CLIP batch size |
| `--model` | `ViT-B/32` | CLIP model variant |
| `--limit` | None | Cap products (useful for testing) |

This creates:
```
data/index/
  catalog.faiss      # FAISS IVFFlat index
  embeddings.npy     # raw float32 embeddings (numpy fallback)
  id_list.npy        # product ID → index mapping
```

## Evaluation

```bash
python src/evaluate.py \
    --validation data/validation.json \
    --index      data/index \
    --top-k      10
```

Reports **Recall@1**, **Recall@5**, **Recall@10**, and **MRR**.

## Python API

```python
from src.pipeline import ShopTheLookPipeline

pipe = ShopTheLookPipeline(index_dir="data/index", top_k=5)

# From a file path
results = pipe.query("my_outfit.jpg")

# From a scene ID
results = pipe.query_scene_id("cdab9160072dd1800038227960ff6467")

for r in results:
    print(f"#{r['rank']} {r['product_id']}  score={r['score']:.3f}  [{r['match_type']}]")
    print(f"  → {r['explanation']}")
    print(f"  → {r['image_url']}")
```

## Match Types

| Label | Cosine similarity | Meaning |
|---|---|---|
| **Exact** | ≥ 0.97 | Likely the same product |
| **Close** | ≥ 0.85 | Very similar style/colour |
| **Similar** | < 0.85 | Shares fashion attributes |

## Future Improvements

- **FashionCLIP**: domain-fine-tuned CLIP for ~5–8 pp Recall@5 gain
- **YOLO fashion detection**: crop individual garments before embedding
- **Multi-vector representation**: per-region embeddings for complex scenes
- **Attribute filtering**: filter results by colour/category before re-ranking
- **Re-ranking**: cross-encoder reranker on top-50 FAISS candidates
- **Full catalog indexing**: IVF-PQ compression for 50k → 1M+ products
